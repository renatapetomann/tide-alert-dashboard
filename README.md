# Tide Alert Dashboard

de acordo com o material anexo aqui, precisamos criar uma plataforma chamada alerta marés na disciplina de plataformas digitais na administração no curso de administração pública da esga. com isso, gostaríamos de utilizar como base o site: "https://radarsc.redmaxx.com.br/" consegues acessar os paineis?

gostariamos fazer a nossa plataforma parecida com o radar sc mas com apenas as informações essenciais como mostradas no arquivo que está anexo aqui e visualmente mais fácil.
